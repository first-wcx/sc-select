# Data Availability

This public snapshot includes:

- reviewed SC-Select prompt and contract metadata;
- JSON schemas for semantic contracts and perception graphs;
- summarized result tables;
- statistical test outputs;
- selected-output metadata and baseline summaries;
- final paper figures and table assets.

This public snapshot excludes:

- generated candidate images;
- model weights and downloaded model caches;
- private server credentials and audit logs;
- submission-system files and journal packaging files;
- large intermediate output folders.

The excluded generated images and raw remote artifacts remain local audit materials. The manuscript reports results through summarized tables and provenance records included in this repository.
